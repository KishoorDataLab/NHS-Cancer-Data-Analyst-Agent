# 🏥 NHS Cancer Data Analyst Agent

An AI-powered Data Analyst Agent designed to simulate how an expert NHS cancer analyst would investigate, process, and interpret cancer-related healthcare data.

The agent automates the complete analytical workflow — from understanding healthcare questions to producing insights and recommendations for decision-making.

---

## 🚀 Project Overview

This AI Agent follows a structured healthcare analytics pipeline:

### 1️⃣ Understand the Problem
✔ Define analysis objectives  
✔ Identify cancer type, patient group & timeframe  
✔ Determine required data fields  

### 2️⃣ Collect & Prepare Data
✔ Gather NHS cancer records  
✔ Clean missing values & inconsistencies  
✔ Merge and preprocess datasets  

### 3️⃣ Analyse the Data
✔ Detect patterns and trends  
✔ Compare patient groups  
✔ Identify possible risk factors  

### 4️⃣ Review Findings
✔ Validate results  
✔ Compare findings with healthcare benchmarks  

### 5️⃣ Generate Final Report
✔ Create visual insights  
✔ Summarize findings  
✔ Provide recommendations for NHS teams
